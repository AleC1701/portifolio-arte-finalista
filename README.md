

# Portfólio de Artes — Design & Finalização Visual

Página web interativa criada para apresentar peças gráficas e visuais desenvolvidas e montadas para diferentes aplicações, com foco em composição, tipografia, contraste e adaptação de formatos.

## O que o projeto apresenta
* **Filtros por categoria:** visualização organizada entre *Cartões & Papelaria*, *Estampas & Vestuário*, *Flyers e Panfletos* e *Logomarcas*.
* **Visualização ampliada com detalhes:** ao clicar em qualquer peça, abre um modal com a imagem ampliada, medidas/formato, cores, acabamento e descrição da montagem visual.
* **Exportação em PDF:** botão no topo para gerar ou imprimir a página diretamente pelo navegador.

## Tecnologias utilizadas
* **HTML5** para estruturação do conteúdo e dos cards das peças.
* **CSS3** para layout responsivo em grade, filtros, modal e estilos de impressão.
* **JavaScript** para filtragem dinâmica por categoria e abertura/fechamento do modal de detalhes.
